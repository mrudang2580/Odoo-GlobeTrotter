# 🌍 GlobeTrotter — “Plan less. Experience more.”

> **GlobeTrotter** is a personalized, intelligent, end-to-end multi-city travel planning platform built for modern travel-tech workflows. It combines the structured workspace agility of Notion, the route intelligence of Google Travel, and the rich experience discovery of MakeMyTrip.

---

## ✨ Features

- **⚡ Fast-Track Judge Demo Mode:** 1-click instant login loaded with realistic multi-city trips (*European Summer Explorer*, *Royal Rajasthan*, *Bali Island Wellness*).
- **🏠 Personalized Central Dashboard:** Hero destination search, live spend vs. budget barometer, upcoming journeys grid, and curated recommendations.
- **🗺️ Multi-Step Trip Planner Wizard:** Configure trip details, pick multiple cities, automatically compute duration and stay dates, and set budget limits.
- **🧭 Interactive 3-Pane Itinerary Builder:**
  - **Left:** Multi-city sequence, transit legs (high-speed rail / flight estimates), stay durations, and add stop controls.
  - **Center:** Day selector tabs, live weather forecast, time-slotted activity cards with category tags, inline editing, up/down reordering, and activity creator.
  - **Right:** Live financial barometer with dynamic Budget Health alerts (`✓ Within Budget` vs `⚠ Over Budget`), daily averages, and quick actions.
- **💰 Financial Dashboard & Budget Breakdown:** Category cost meters (Accommodation, Transport, Activities, Food, Shopping, Visa), day-by-day expenditure bar charts, and custom expense logger.
- **📅 Interactive Calendar & Timeline:** Multi-day cards grid and continuous vertical Gantt timeline views.
- **🌍 Global Discovery Hub:** Explore filterable destinations (by region and cost index) and activities across 8 categories.
- **🗺️ Interactive Route Map:** Leaflet OpenStreetMap with connected multi-city polyline vectors and interactive waypoint popups.
- **🔗 Public Shareable Itinerary & 1-Click "Copy Trip":** Shareable guest-friendly URL with 1-click cloning of the entire itinerary into the user's workspace.
- **👤 Profile, Preferences & Admin Analytics:** Custom currency settings (INR, USD, EUR, GBP, AED, JPY, SGD), saved bucket list, and platform telemetry analytics.

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS v4 + Custom Travel-Tech Design System
- **Icons:** Lucide React
- **Mapping:** Leaflet + React-Leaflet + OpenStreetMap
- **State & Storage:** Reactive Relational Engine with `IndexedDB` & `localStorage` persistence
- **Delight:** Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/labdhimehta-2311/ODOO-TRAVEL.git

# Navigate to directory
cd ODOO-TRAVEL

# Install dependencies
npm install

# Start local development server
npm run dev
```

The application will be available at `http://localhost:5173/`.

### Build for Production
```bash
npm run build
npm run preview
```
