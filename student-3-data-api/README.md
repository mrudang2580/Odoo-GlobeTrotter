# 📊 GlobeTrotter — Data & AI Integration Repository (Student 3)

Travel dataset pipelines, budget estimation engines, and activity recommendation microservices.

---

## 📁 Contents
- `data/cities.csv`: 40 global destinations with cost indexes and popularity metrics.
- `data/activities.csv`: 80+ curated experiences with category and cost mappings.
- `scripts/budget_estimator.py`: Heuristic budget calculation service.
- `scripts/recommender_api.py`: Personalized activity recommendation service.
- `notebooks/data_pipeline.ipynb`: Colab notebook for data exploration.

---

## 🚀 How to Run Locally

```bash
pip install -r requirements.txt
python scripts/budget_estimator.py
python scripts/recommender_api.py
```
