# ⚛️ GlobeTrotter — Student 2: Next.js 14 + Tailwind CSS Frontend

**Owner**: [@angels31206](https://github.com/angels31206) (Frontend Engineer)  
**Framework**: Next.js 14 (App Router), React 18, TypeScript, Tailwind CSS, Lucide Icons

---

## 📱 Implemented 13-Screen Matrix

| Screen # | Feature Screen | App Router Route | Description |
| :--- | :--- | :--- | :--- |
| **1** | **Login & Signup** | `/login`, `/signup` | Auth state simulation, form validation, profile onboarding |
| **2** | **Dashboard / Home** | `/` | Hero search, quick actions, KPI stats grid, trending destinations |
| **3** | **Create Trip Wizard** | `/trips/create` | Multi-step trip planner, date range, budget limit & cover picker |
| **4** | **My Trips (List)** | `/trips` | Status filter tabs (Upcoming, Ongoing, Completed), search filter |
| **5** | **Itinerary Builder** | `/trips/[id]/build` | Multi-city legs, add/remove stops, assign custom activities & costs |
| **6** | **Itinerary View** | `/trips/[id]` | Day-by-day structured itinerary timeline with city summaries |
| **7** | **City Search** | `/cities` | Filter by continent/region, cost index, popularity score modal |
| **8** | **Activity Search** | `/activities` | Category filter (sightseeing, food, adventure, culture), search bar |
| **9** | **Budget Breakdown** | `/trips/[id]/budget` | Category distribution bars, daily expense list, currency switcher |
| **10** | **Trip Calendar** | `/trips/[id]/calendar`| Chronological daily view of activities & transfers |
| **11** | **Shared Itinerary** | `/share/[slug]` | Public view for community sharing, one-click clone/fork action |
| **12** | **User Profile** | `/profile` | Editable traveler preferences, currency/language settings |
| **13** | **Admin Dashboard** | `/admin` | Telemetry KPIs, top destinations, activity volume leaderboards |

---

## 🚀 Quick Setup & Run

```bash
cd student-2-frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.
