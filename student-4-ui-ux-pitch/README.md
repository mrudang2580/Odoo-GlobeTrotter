# 🎯 GlobeTrotter — UI/UX Design & Pitch Repository (Student 4)

Design tokens, Figma-ready screen specifications, user personas, pitch presentation script, and interactive HTML slide deck.

---

## 📁 Contents
- `pitch/index.html`: Interactive browser-based Pitch Deck (keyboard navigated).
- `pitch/PITCH_SCRIPT.md`: 3-minute hackathon judge demo speech script.
- `design-tokens/tokens.json`: Design system color palette, typography & spacing tokens.
- `design-tokens/tailwind-theme.js`: Tailwind configuration preset.
- `specs/design_spec.md`: Comprehensive 13-screen UI/UX specifications.
- `specs/user_personas.md`: Target personas & user journey maps.
