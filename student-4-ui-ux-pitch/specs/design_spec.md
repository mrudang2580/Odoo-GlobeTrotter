# 🎨 GlobeTrotter Design Specification & UI Guidelines

## 📐 Grid & Layout
- **Container**: Max width 1280px (7xl) centered with responsive horizontal padding (px-4 on mobile, px-8 on desktop).
- **Cards**: Border radius `rounded-2xl` (16px) or `rounded-3xl` (24px) with subtle `border-slate-200` and soft elevation shadows.
- **Micro-Interactions**: Hover elevation `-translate-y-1` and smooth 300ms transition curves.

## 🎨 Color System
- **Primary / Brand**: Sky Blue `#0284c7` (Brand 500) to Deep Navy `#0c4a6e` (Brand 800)
- **Accent**: Warm Amber `#f59e0b` (Accent 500)
- **Status Colors**:
  - Success / Budget Safe: Emerald `#10b981`
  - Warning / Exceeding: Amber `#f59e0b`
  - Alert / Over-budget: Crimson `#ef4444`

## 🔤 Typography Hierarchy
- **Headings**: Plus Jakarta Sans, font-extrabold / font-black (700 / 800 / 900)
- **Body**: Plus Jakarta Sans, regular / medium (400 / 500), line-height 1.5
- **Badges / Tags**: Uppercase tracking-wider, font-bold, text-xs (11-12px)
