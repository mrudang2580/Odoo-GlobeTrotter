# ♿ Accessibility (a11y) & WCAG 2.1 AA Compliance Audit

- **Color Contrast**: All text elements meet or exceed 4.5:1 contrast ratio against light surface backgrounds.
- **Keyboard Navigation**: Focus outlines enabled on all interactive buttons, modal close triggers, and tab switches.
- **Screen Reader Support**: Semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<button>`) utilized throughout.
- **Alt Text**: All destination imagery and activity thumbnails provide contextual descriptive alt tags.
